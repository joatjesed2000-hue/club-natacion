# Club de Natación Tiburones · Popayán

Página mejorada del club, preparada para la cuenta GitHub `joatjesed2000-hue`.

## Dirección prevista

https://joatjesed2000-hue.github.io/club-natacion/

La dirección se activará después de subir estos archivos al proyecto público
`club-natacion` y habilitar GitHub Pages. Este archivo no confirma su publicación.

## Publicación

1. Crear un repositorio público llamado `club-natacion` en la cuenta indicada.
2. Subir el contenido de esta carpeta a la raíz del repositorio, de forma que
   `index.html` quede directamente en la raíz.
3. En Settings → Pages, seleccionar Deploy from a branch, la rama con los
   archivos (por ejemplo `main`), la carpeta `/ (root)` y guardar.

## Contenido

- Inicio con historia, categorías, logros, equipo y Plan Padrino.
- Galería con fotografías originales del club.
- Calendario con las fechas publicadas por el club.
- Contacto y redes del club conservados.

Sitio estático: no necesita instalar dependencias ni ejecutar una compilación.
Las fotografías y logotipos originales se conservan sin aplicar una nueva licencia.
